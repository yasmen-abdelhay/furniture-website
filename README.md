# VibeSpaces – Furniture & Interior Design Website

A modern and elegant furniture and interior design website built using HTML5 and CSS3.

## 🌐 Live Demo
[View Website](https://yasmen-abdelhay.github.io/furniture-website/)

## ✨ Features
- Modern and clean user interface.
- Furniture collections and product showcases.
- Interior design services and packages.
- Organized sections for an engaging browsing experience.

## 🛠️ Technologies Used
- HTML
- CSS

## 📂 Project Structure
- `index.html` – Main website structure.
- `css/` – Stylesheets.
- `images/` – Website images and assets.
- `webfonts/` – Font files.
